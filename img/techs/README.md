# Tech logos

`TechCard.vue` loads a logo from `/img/techs/<slug>.png`. If the file is missing,
the card falls back to the tech's initials, so adding images is optional.

Slug rule: lowercase, `+` → `plus`, `#` → `sharp`, any other non-alphanumeric run → `-`.
